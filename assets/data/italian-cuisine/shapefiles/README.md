# Istat regional boundaries

The `Reg01012025_WGS84` files are the generalized regional layer from
Istituto nazionale di statistica (Istat), *Confini delle unità amministrative
a fini statistici*, reference date 1 January 2025.

- Source: <https://www.istat.it/notizia/confini-delle-unita-amministrative-a-fini-statistici-al-1-gennaio-2018-2/>
- License: [Creative Commons Attribution 4.0](https://creativecommons.org/licenses/by/4.0/)
- Attribution: Istituto nazionale di statistica (Istat)

The source shapefile is reprojected to EPSG:4326 when needed and its geometry
is simplified with topology preservation when the website's Plotly maps are
generated. These changes are not endorsed by Istat.
